# Resumo Executivo

O projeto Crop Track propoe o uso de drones equipados com sensores para monitorar plantacoes de culturas perenes em larga escala, oferecendo uma solucao **B2B** voltada a clientes de grande porte.

## Estado Atual

No primeiro modulo (XIIV), desenvolvemos um modelo de classificacao multi-classe capaz de identificar 5 tipos de doencas em folhas de cafe: Cercospora, Leaf Rust, Miner, Phoma e Healthy. Porem, o modelo atual apresenta acuracia de apenas **60-70%**, insuficiente para uso confiavel em producao.

## Objetivo do Modulo XV

**Elevar a acuracia do modelo multi-classe de 60-70% para no minimo 85%**, atraves de:

- Melhoria da qualidade e balanceamento do dataset
- Otimizacao da arquitetura e hiperparametros do modelo
- Aplicacao de tecnicas avancadas de treinamento
- Validacao com imagens reais de campo

## Por que 85%?

Uma acuracia de 85%+ significa que o modelo acerta o diagnostico em pelo menos **17 de cada 20 analises**, um patamar aceitavel para uso em campo como ferramenta de apoio a decisao. Abaixo disso, o risco de diagnosticos errados e alto demais para justificar a adocao pelo produtor.

## Valor para o Negocio

Com a acuracia elevada, a solucao passa a ser **confiavel o suficiente para comercializacao**. Ao finalizar este modulo, o Crop Track tera o nucleo tecnologico necessario para sustentar a fase de **business**: modelo de receita SaaS, go-to-market e captacao de clientes piloto.
