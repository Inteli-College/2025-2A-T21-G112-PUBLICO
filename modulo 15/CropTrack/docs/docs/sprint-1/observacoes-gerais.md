# Observacoes Gerais

### Desafios Previstos
- Fechar o gap de 15-25 pontos percentuais de acuracia (de 60-70% para 85%+)
- Balanceamento do dataset entre as 5 classes de doencas
- Similaridade visual entre algumas doencas (ex: Cercospora vs Phoma)
- Gap entre imagens de laboratorio e imagens reais de campo
- Necessidade de infraestrutura computacional para treinar e iterar modelos
- Calibracao para diferentes sensores e condicoes de captura dos drones

### Oportunidades
- Modelo com 85%+ abre caminho para comercializacao
- Escalabilidade da solucao para outras doencas alem das 5 iniciais
- Potencial de uso do mesmo pipeline em outras culturas alem do cafe
- Integracao com sistemas de recomendacao de manejo automatizado
- Modelo otimizado como diferencial competitivo frente a solucoes genericas do mercado

### Hipoteses a Serem Validadas
- A melhoria do dataset (qualidade e balanceamento) impacta diretamente a acuracia
- Tecnicas avancadas de data augmentation ajudam a fechar o gap de performance
- O modelo otimizado mantem a acuracia de 85%+ quando testado com imagens reais de campo
- O processamento e rapido o suficiente para aplicacoes quase em tempo real

### Possiveis Melhorias Futuras
- Continuar elevando a acuracia para 90%+ em iteracoes futuras
- Inclusao de algoritmos de deteccao precoce baseados em series temporais
- Implementacao de alertas automaticos por tipo de doenca no dashboard
- Otimizacao do modelo para execucao em dispositivos embarcados ou de borda
- Expansao para mais classes de doencas conforme novos datasets forem disponiveis

### Transicao para Business

Ao concluir este modulo com a meta de 85%+ atingida, o foco migrara para o **lado business** da solucao:

- **Modelo de receita:** Estruturacao do SaaS com precificacao por hectare ou por analise
- **Go-to-market:** Estrategia de entrada no mercado via clientes piloto (grandes cafeicultores)
- **Parcerias estrategicas:** Cooperativas, distribuidores de insumos, empresas de drones
- **Captacao de investimento:** Preparacao de pitch e materiais para investidores
- **Validacao de mercado:** Testes com produtores reais para medir willingness to pay
- **Dashboard comercial:** Prototipo da interface de entrega de valor ao cliente final
